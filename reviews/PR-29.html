AI PR Reviewer Note / AI PR 审阅说明

一、概述 / Summary

本次修改修复了 CI 工作流在只读令牌场景下尝试写 PR 评论导致任务异常失败的问题，并补充本 PR 的双语 reviewer 说明文件。

These changes fix the CI workflow so it no longer crashes when posting PR comments with a read-only token, and add the required bilingual reviewer note for this PR.

二、变更内容 / Changes

  • .github/workflows/ai-pr-reviewer-note.yml：将 PR 评论发布改为“尽力而为”；评论失败时记录 warning 并继续执行真正的校验逻辑。
  • reviews/PR-29.html：新增本 PR 的中英文审阅说明。

三、AI 参与披露 / AI Participation Disclosure

  • 工具与模型 / Tool & model：GitHub Copilot Coding Agent。
  • 参与范围 / Extent：工作流脚本小范围修改与说明文件撰写。
  • 人工复核 / Human review：已人工检查失败日志、变更内容和命令执行结果。

四、验证与测试 / Verification & Testing

  • 通过 GitHub Actions 日志确认根因为 Resource not accessible by integration (addComment)。
  • 本地运行针对性检查：git diff --check，并人工复核工作流脚本逻辑。

五、风险与已知问题 / Risks & Known Issues

当令牌具备写权限时，评论仍会正常发布；当令牌只读时将仅输出 warning，不影响校验成败判定。

When write permission is available, the workflow still posts comments. With read-only tokens, it now emits a warning without masking the real check result.
