一、概述 / Summary

本 PR 实现 issue #32：补齐主线做不到的那件事——**用一张任意参考图决定输出风格**。新增 impl/stylize/（AdaIN），提供命令行与界面两个入口，并对 AdaIN 做了一次完整的 INT8 量化对照实验。支线与主线并列而非嵌套：CycleGAN 换实例外观，AdaIN 换画风，指标不与 A/B/C 混表，产物不写 artifacts/results/。

This PR implements issue #32: it adds impl/stylize/ (AdaIN) so that a reference image can drive the output style — something the CycleGAN main line cannot do. It ships both a CLI and a web entry point, plus a full INT8 quantization ablation. The branch is parallel to, not nested in, the A/B/C main line: CycleGAN changes instance appearance while AdaIN changes painting style, so their metrics are not tabulated together.

五、风险与已知问题 / Risks & Known Issues

  1. 未接感知指标：本机 venv 无 torchvision，LPIPS/FID 未接入；当前只有 PSNR/SSIM。No perceptual metrics yet (no torchvision locally).
  2. IR 为静态形状：OV / INT8 固定 256 输入，与 PyTorch 后端的原分辨率不一致（UI 已注明）。Static-shape IR at 256 for the OV/INT8 backends.
  3. 权重与图片不入库：94 MB 权重 + 第三方画作（版权），由 download / fetch-samples 获取；CI 环境无法跑端到端，只能做语法检查。Weights and third-party images are not committed; CI cannot run end-to-end.
  4. 分辨率敏感性：用 256 校准的 INT8 跑 512 会掉到 16.5 dB，换分辨率必须重校准。已在 README 写明。Calibration resolution must match inference resolution.
