一、概述 / Summary

伙伴可以从仓库复制运行所需源码和配置，在独立目录保存自己的模型与结果。切换迁移对后，E4 展示该对的层间结果，E3 的网页、实验进度卡片和导表按同一口径解释有效批次、缺失项与指标开关。

The launcher builds a separate runtime while preserving local models and results across resynchronization. E4 reads layer data for the selected pair. E3 retains usable classification batches and explains missing or disabled metrics across the web panel, progress card and Markdown export.

人工复现 / Run the four-pair review

从仓库根打开 PowerShell，使用项目 Python 3.12 CPU 环境。默认读取 .venv，也可通过 E3_PYTHON 指定解释器。首次安装见 docs/REPRODUCING_T0_T1.md。在浏览器检查“03 质量评测”和“04 实验进度”，完成后 Ctrl+C 停服。
Run the block from the repository root with the project CPU environment. Inspect the Quality and Progress tabs, then stop the server with Ctrl+C.

$repo = (Resolve-Path .).Path
$py = if ($env:E3_PYTHON) { $env:E3_PYTHON } else { (Resolve-Path '.venv/Scripts/python.exe').Path }
$run = Join-Path ([IO.Path]::GetTempPath()) ('ShiftLite 复核-' + [guid]::NewGuid().ToString('N'))
$launcher = Join-Path $repo 'impl/run-local.ps1'
$port = 18770
& $launcher -Python $py -RunRoot $run -CliArgs @('figures','--help')
if ($LASTEXITCODE -ne 0) { throw '同步失败' }
$work = Join-Path $run 'impl'
$art = Join-Path $work 'artifacts'
foreach ($id in 'horse2zebra','summer2winter','zebra2horse','style_monet') {
    $base = if ($id -eq 'horse2zebra') { $art } else { Join-Path $art $id }
    $res = Join-Path $base 'results'
    $null = New-Item -ItemType Directory -Path $res -Force
    $file = Join-Path $res 'quality.json'
    if ($id -in @('horse2zebra','summer2winter')) {
        Copy-Item -LiteralPath (Join-Path $work 'tests/e3_partial_b_only.json') -Destination $file
        & $launcher -Python $py -RunRoot $run -CliArgs @('figures','--pair',$id)
        if ($LASTEXITCODE -ne 0) { throw "figures $id" }
        Get-Content -LiteralPath (Join-Path $base 'figures/quality_table.md') -Encoding utf8 -ErrorAction Stop | Select-String '任务保真'
    } elseif ($id -eq 'zebra2horse') {
        [IO.File]::WriteAllText($file,'{"metrics_source":"proxy","mean":{"ssim_bc":0.9},"rows":[],"n_samples":1}')
    }
}
"RunRoot=$run"
"http://127.0.0.1:$port/"
& $launcher -Python $py -RunRoot $run -CliArgs @('serve','--host','127.0.0.1','--port',"$port")

依次切换 horse2zebra（B 75.00%，缺 C）、summer2winter（分类不适用）、zebra2horse（代理）、style_monet（无数据），再切回默认对。
Expect a partial B batch, disabled classification, proxy metrics and an empty state respectively. Return to the first pair and confirm its measured value is restored.

五、风险与已知问题 / Risks & Known Issues

上述快速流程使用合成 JSON，无需模型权重。实图推理需要另行准备模型与样图。重复导出时以当次产物清单为准，旧副表可能仍在磁盘上。异机、Linux/macOS 和全新依赖安装尚待独立复验。
The walkthrough uses synthetic results. Live inference requires model and image assets. Check the current output list when reusing a directory, since an older secondary table may remain. A second machine, other operating systems and a fresh dependency install remain unverified.
