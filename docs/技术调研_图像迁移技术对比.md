# 技术调研：图像迁移技术实现对比与本项目扩展性

背景：指导老师 2026-10-25 意见——马→斑马应用范围窄，图像处理技术换对象/换域往往容易，要求探讨其他技术的实现方式并评估功能扩展。开题报告不动，本调研作为期末报告/视频/答辩的拓展素材，同时是 #24（迁移对扩展）的设计依据。

## 1 对比总表

| 路线 | 代表 | 实现机制 | 训练数据 | 换域/换对象成本 | 推理形态 |
|---|---|---|---|---|---|
| 有配对翻译 | pix2pix（CVPR 2017）/ pix2pixHD（CVPR 2018） | cGAN + L1 重建 + PatchGAN；HD 版粗到精多尺度判别 | 成对数据 | 重训（含数据采集） | 单 G 前向 |
| 无配对翻译 | CycleGAN（ICCV 2017，本项目） | 双 G + 双 D + 循环一致损失（λ=10） | 两域非成对 | 换权重或重训 | 单方向 G 前向 |
| 对比学习翻译 | CUT（ECCV 2020） | 单 G + PatchNCE：输出与输入同位 patch 拉近、与异位 patch 拉远，替代循环一致性 | 单域即可 | 重训 | 单 G 前向 |
| 多域单模型 | StarGAN（CVPR 2018）/ StarGAN v2（CVPR 2020） | 域标签/域风格码作条件输入 + 域分类损失；v2 加风格编码 + AdaIN，多样输出 | 多域同堂 | 加域扩标签 + 重训/微调 | G(x, 域码) |
| 扩散式编辑 | SDEdit / LDM / ControlNet | 预训练大模型加噪到中间步，按条件（文本/边缘/深度）去噪 | 大模型预训练，任务侧免训 | 换 prompt/条件/微调 | 迭代去噪（多步） |
| 传统方法 | 颜色迁移（Reinhard 2001）/ AdaIN 风格迁移 / 纹理合成 | 输出 = 输入 + 目标统计量（均值方差匹配、特征统计量对齐） | 无 | 换参考图/统计量 | 单次前处理级计算 |

## 2 换域成本的三种机制（老师问「换别的为什么容易」的直接答案）

| 机制 | 代表 | 换对象时动什么 | 本项目归属 |
|---|---|---|---|
| 条件外置 | StarGAN 域码、扩散 prompt、AdaIN 风格图 | 只换条件输入，权重不动 | 否 |
| 权重插拔 | CycleGAN / pix2pix / CUT | 换权重文件，架构不动 | **是** |
| 统计量替换 | 颜色迁移、纹理合成 | 换参考统计量 | 否 |

本项目属「权重插拔」型：易扩展不靠改架构，靠权重可插拔 + 配置化。官方 pytorch-CycleGAN-and-pix2pix 提供 18 个预训练对（apple2orange / orange2apple、summer2winter_yosemite / winter2summer_yosemite、horse2zebra / zebra2horse、monet2photo、style_monet / cezanne / ukiyoe / vangogh、sat2map / map2sat、cityscapes 双向、facades 双向、iphone2dslr_flower），全部同一生成器架构（resnet_9blocks + InstanceNorm），换权重即换应用。本项目已实证该架构 PyTorch 直转 OpenVINO IR 误差 max|Δ|=9e-6、NNCF PTQ 链路可用，扩展不触碰推理与量化链路。

## 3 代表性数字（对照用，口径不同勿直接比）

| 来源 | 数字 | 说明 |
|---|---|---|
| CUT 论文（arXiv v3, Park 2020） | horse→zebra FID 45.5（CUT）vs 77.2（CycleGAN）；训练快约 40%、省显存约 31% | CUT 用对比损失换掉循环一致性的收益 |
| 本项目实测（n=120/140） | FID(B 批 vs testB) = 80.70 | 与 77.2 同量级；评测集切分与 Inception 预处理口径不同，不与 CUT 的 45.5 直接比 |
| StarGAN 系 | 换域不换权重 | 要求多域数据同堂训练，与「一权重一对」的量化/层间分析框架不兼容 |

## 4 选型结论（2026-10-25 拍板）

1. 扩展走**预训练权重复用 + pair 配置化**（落地见 #24）。量化加速与层间分工的既有结论在同架构内连续，零训练成本；18 个官方对覆盖实例纹理、全局域、风格、反向四类迁移，可支撑「层间分工随迁移类型变化」的对比分析。
2. 不引入 CUT / StarGAN / 扩散引擎。换引擎使已建立的 A/B/C 量化对照与 15 探针层口径全部失效，答辩需同时解释两套技术栈；三者结论只作对照引用。
3. 风险：出图质量由官方权重决定，个别对可能质量弱。负结果沿用 E3 异常登记口径如实记录，不挑图。
