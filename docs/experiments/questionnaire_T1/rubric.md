# 主观评分标准（#15 · PLAN §4 兜底指标）

> 盲评：每对左右分别为 FP32(b) 与 INT8(c) 的生成图，左右顺序随机；打分人**不知道**哪边是 INT8。
> 四项各 1–5 分（整数），对左右两侧**分别**打分；先看整体，再对每一项独立给分。

## 四项定义与锚点

| 项 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 视觉自然度 | 明显崩坏/畸形，无法接受 | 有可见瑕疵但可辨认 | 自然真实，无明显瑕疵 |
| 斑马特征 | 完全不像斑马（仍是马） | 部分条纹/斑马特征较弱 | 明确斑马条纹与外观 |
| 姿态与结构保留 | 严重形变、错位或主体丢失 | 轮廓基本保持但有偏移/变形 | 姿态、轮廓、位置基本保持 |
| 背景保留 | 背景被大幅改写 | 背景有可见变化 | 背景基本不变 |

## 判定口径
- 主体是否可辨认、斑马特征是否成立、姿态/位置是否保持、背景是否被改写，四项独立。
- 「有斑马条纹但仍像马」按斑马特征给中低分，不要把轮廓保持误当迁移成功。
- 检测掩码不在打分材料中；只依据左右两张生成图。
- 不确定时在 `notes` 写清原因，分数仍按最接近的档位。

## 汇总口径
- 对每项分别计算 FP32 与 INT8 的均值±标准差（左右先按 `answer_key.csv` 还原组别）。
- 成对比较使用 Wilcoxon 符号秩检验（配对）；报告差值方向与显著性。
- 可选：计算评分者间一致性（如 ICC/Krippendorff α），并单列评分人数与样本数。
- **不得**把四项合成单一「总分」；如确需总览，四项并列报告。
