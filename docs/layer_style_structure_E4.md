## 3 判读结论

1. **漂移沿深度单调累积**：最浅的 down 段几乎不变，越靠输出漂移越大，最大值落在 `resblock_09`。这与“量化误差逐级放大”的预期一致。
2. **风格/感知与结构呈不同的敏感度**：深层残差漂移约 3.6%（0.9994→0.9644），而浅层仅约 0.04%（0.9996），降幅明显不同步；对应的 LPIPS(b,c)=0.099 有可测退化，而结构类指标（IoU 0.814 / Dice 0.850 / Canny 0.620）仍保持较高。**支持“风格信息比结构/位置信息更易被数值精度扰动”的判读**。
3. **方向不变性旁证**（#24）：`zebra2horse` 的残差块同样 0.9995→0.9649、最大漂移仍在 `resblock_09`，说明该分工形态主要与架构/量化有关，而非迁移方向。
4. **对应 #17 的失真类型**：轮廓/位置类失真应对应浅层与掩码指标；背景改写对应解码/背景 SSIM；纹理颗粒与部分结构异常对应深层残差与输出头。

## 4 边界与局限

- 层间余弦/相对 L2 是**表示相似度**，不是语义因果证明；“风格/结构”是判读标签，不是严格定义。
- LPIPS 是深度特征距离，不能直接等同于“风格”；FID/KID 衡量分布距离，不是单图逼真度。
- 本判读基于单模型单 pair；跨类型外推仅以 #24 的方向不变性作初步旁证。
- 结论是“与指标同向的关联证据”，不宣称“某层负责某语义”。
