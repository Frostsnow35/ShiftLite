# 基于 CycleGAN 的实例对象图像迁移应用——量化加速与网络层间分工分析

> 《人工智能导论》课程项目 ｜ 代号：移形换影 ShiftLite
> 仓库名：`ShiftLite` ｜ 组队：4 人

## 项目简介
把一种对象的视觉外观迁移到另一种（如马 → 斑马），做成一个能用的本地迁移应用（Web Demo：传图 → 选迁移对 → 实时出图），并用量化加速部署；同时以量化扰动为探针，给出网络层间分工分析——哪层编码风格、哪层编码结构，作为项目深度。

## 核心内容
- **迁移应用（主角）**：基于 CycleGAN 的无配对图像到图像翻译，做成可现场演示的 Web Demo。
- **量化加速与性能对比（工程价值）**：PyTorch → OpenVINO IR 直转（`ov.convert_model`）+ INT8，A/B/C 三组同源权重（C 为确定性量化版本）、只变运行环境与数值精度，对比延迟/吞吐/体积/质量。
- **网络层间分工分析（深度）**：PyTorch 域内前向钩子取残差块特征图（量化侧 NNCF 同配置模拟），逐层余弦相似度 + 相对误差刻画层间漂移，定位风格/结构编码层。
- **训练复现（佐证）**：Colab 小规模训练 horse2zebra，曲线 + 与官方权重对比，证明吃透方法（与主对照隔离）。
