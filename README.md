# 轻迁 CycleLite

> 基于实例对象图像迁移与轻量化推理加速的《人工智能导论》课程项目
> 仓库名：`qiantu-lite` ｜ 代号：轻迁 CycleLite ｜ 组队：4 人

## 项目简介
把一种对象的视觉外观迁移到另一种（如马 → 斑马、苹果 → 橙子），用通用的无配对图像翻译方法表征并迁移图像风格；并把生成模型在 Intel 硬件上做轻量化推理加速，让"能出图"进一步做到"能快部署"。

## 核心内容
- **实例对象迁移**：无配对图像到图像的翻译，覆盖多组迁移对。
- **轻量化推理加速**：将生成模型转换为 OpenVINO 中间表示并做 INT8 量化，在本地 Intel CPU / 集成显卡上加速推理。
- **可量化对比**：PyTorch 原始推理 vs OpenVINO 优化推理（延迟 / 吞吐 / 体积 / 质量）。
