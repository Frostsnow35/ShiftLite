# 基于 CycleGAN 的实例对象图像迁移——量化扰动下的语义归因与层间分工分析

> 《人工智能导论》课程项目 ｜ 代号：移形换影 ShiftLite
> 仓库名：`ShiftLite` ｜ 组队：4 人

## 项目简介
把一种对象的视觉外观迁移到另一种（如马 → 斑马、苹果 → 橙子），用通用的无配对图像到图像翻译方法表征并迁移图像风格；并以模型量化（INT8）作为**可控扰动探针**——保持网络结构与权重不变，只改变运行环境与数值精度，配合语义归因与中间层表示分析，回答"深度神经网络中哪一层编码风格、哪一层编码结构"。本项目正面回应课程指南对"图像表示中与风格相关的特点"的研究要求。

## 核心内容
- **实例对象迁移**：基于 CycleGAN 的无配对图像到图像翻译，覆盖多组迁移对。
- **量化扰动作为可控探针**：A/B/C 三组"同权重、只变运行环境与数值精度"的干净控制对照，经 PyTorch → ONNX → OpenVINO IR 转换并做 INT8 量化，构成量化扰动实验链（量化是手段，不是研究主题）。
- **语义归因与层间分工**：沿风格轴（LPIPS + 斑马判别）/ 结构轴（掩码 IoU + Canny 边缘 SSIM）/ 背景轴（背景区 SSIM）做语义归因；用前向钩子取残差块特征图，逐层余弦相似度 + 相对误差刻画层间漂移，定位风格/结构的编码层。
